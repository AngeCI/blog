# 聲母
## 音系構擬
本文假設：
- 知照已經合流。
- 牙喉音分為腭化與非腭化兩組。這一項對於音譯外語來說不是那麼的重要，但是能解釋一些更後來的《中原音韻》和《蒙古字韻》中的對立小韻。
- 我目前選擇保留中古濁音聲母，但畢竟在宋代濁音清化都在進行中了，因此這不是必須嚴守的定律。

# 音譯原則
- 區分平翹、尖團。
    - Lisa → 立夏 lip ça ✖
    - Nasim → 捺心 nɑɾ sim ✔
    - Nasim → 納棎 nɑp ʒiɛm ✖
    - Zetterstrand /ˈsɛtːəʂˌtrand/ → 截瀦悉蘭 dziɛɾ tʂu siɾ lan ✖
    - Zetterstrand /ˈsɛtːəʂˌtrand/ → 截致丹 dziɛɾ tʂʅ tan ✖
    - Zetterstrand /ˈsɛtːəʂˌtrand/ → 截突譠 dziɛɾ tʰuəɾ tʂan ✔
        - 瑞典語中只有前面跟着 r 的 d t n l s 才是捲舌音。此例中「瀦致」均被用於對應平舌音 tt，可以對應為翹舌音的 rstr 反而用了平舌音。
    - Zając /ˈzajɔnt͡s/ → 紗藥 ʂa jiɔʔ ✖
        - 第一個音節平翹不分；第二個音節誤判原音。
    - España → 士班雅 ʐʅ pan ɲa ❔
        - 「士班雅」一名始見於清代《聖經》譯本，能否符合宋代音系成疑。
    - Castilla → 干係臘 kan çi lɑp ✖
        - 此名見於《明史》，尖團已經不分。尖團聲母在現代粵客閩方言的聽感差異極大，如果要對應宋代音系的話，寧願捨棄其他部份也最好保全尖團。明代的其他文獻有「乾絲臘」、「乾絲蚋」等譯名。
- 牙喉音聲母不區分三等與非三等，與初唐音系有異。
- 「兒爾」等字在宋代的發音大概是 /ȵi/，變成 /ɚ/ 是明代的事了。

# 韻母
## 音系構擬
本文假設：
- 假攝、遇攝已經高化：合於各現代漢語方言，異於各域外方音。不過某些歌韻字直到現代都還沒高化仍維持類似 /a/ 的發音，音譯時容許靈活處理。
- 蟹止已經合流：合於大部份現代漢語方言，異於閩南語文讀與粵語。
- 梗曾已經合流：合於大部份現代漢語方言，異於粵客贛方言。
- 介音採用近代漢語的「四呼」體系，不使用韻圖的「四等二呼」體系。
- 宋代入聲實際押韻狀況混亂。此處假設 -k 為 -ʔ、-t 為 -ɾ、-p 不變。

# 音譯原則
- 不要忽略入聲。
    - Lyrmark → 律麥 lyɾ məʔ ✔
    - Lyrmark → 劉罵 liəu ma ✖
        - 「罵」用字不雅，發音也對不上，建議改成「麥」。
    - Stockholm → 士多貢 ʐʅ tɔ kuŋ ❔
- 塞音結尾音節盡量（儘管不必嚴守）用同部位或近部位的入聲字來譯。
    - Nederland → 尼德蘭 ni təʔ lan ⭕️
        - 「德」屬於遠部位入聲，也許換成「突」更好。
- -l, -r 或 -s 結尾的音節，可以用 -t 尾入聲字來譯。
    - Markus → 末骨思 m(u)ɑɾ kuəɾ sɿ ✔
    - Markus → 禡忌於易斯 ma (g/ɟ)i ʔ(y/iu) ji sɿ ✖
- 入聲字最好不要拿來對應非入聲的音節，除非能把緊隨其後的輔音借來用。
    - Mississippi → 密西西比 miɾ si si p(ʲ)i ✔
    - Mississippi → 密士失必 miɾ ʐʅ ʃiɾ p(ʲ)iɾ ✖
        - 「密士失必」據說出自一本 1980 年代的書籍，與宋代音系無關。
        - 「pi」非入聲音節，也沒有緊隨其後可以借用的輔音。
        - 「士失」皆為翹舌音聲母，不可拿來對應原文的平舌輔音。
        - 現今常用的官話音譯「密西西比」倒是可以符合宋代音譯習慣。
