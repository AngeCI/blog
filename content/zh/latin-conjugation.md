# 序言
拉丁語的動詞變位由 4-5 個相互交織的維度共同決定：
- 變位法（conjugation class）
- 人稱及人數（person & number）：三種人稱各自有單數和複數，合共有六種組合。
- 時態–體貌（tense-aspect）：現在時、未完成時、將來時、完成時、過去完成時、將來完成時（present, imperfect, future, perfect, pluperfect, future perfect）。
- 語態（voice）：主動與被動（active & passive）。
- 語氣（mood）：直陳、虛擬與祈使（indicative, subjunctive & imperative）。

# 動詞分類
拉丁語的動詞詞目通常有四個條目，展示了拉丁語動詞的四種詞幹。

拉丁語的動詞傳統上分為四種變位法，可從動詞的第二條目的結尾推斷：

| 變位法 | 主動 | 被動 |
| -- | -- | -- |
| 1st (ā-stem) | -āre | -ārī |
| 2nd (ē-stem) | -ēre | -ērī |
| 3rd (ĕ/ĭ-stem) | -ere | -ī |
| 4th (ī-stem) | -īre | -īrī |

和[名詞](/blog/zh/latin-nouns-declension/)一樣，動詞的第三變位法有兩個亞種，它們在第一條目的表現有點不一樣。

如果一個拉丁語動詞的不定式結尾與上表列出的不符，那它就是無法被歸入任一變格法的不規則動詞。

拉丁語的動詞變位法實際上是兩種系統的交織。大多數比較能產的第一和第二變位法動詞，完成詞幹是從現在詞幹推出來的。而第三變格法動詞的完成詞幹，則通常來自另一較古老的層次，詞幹構成方式多種多樣。下表顯示各種變位法的各種時態第一人稱單數主動形式：

|  | 1st (ā-stem) | 2nd (ē-stem) | 3rd (ĕ-stem) | 3rd (ĭ-stem) | 4th (ī-stem) |
| -- | -- | -- | -- | -- | -- |
| 現在時 | -ō | -eō | -ō | -iō | -iō |
| 不定式 | -āre | -ēre | -ere | -ere | -īre |
| 未完成時 | -ābam | -ēbam | -ēbam  | -ēbam  | -iēbam |
| 將來時 | -ābō | -ēbō | -am  | -iam  | -iam |
| 完成時 | -āvī | -uī | -ī | -ī | -īvī |
| 過去分詞 | -ātum | -itum | -tum | -tum | -ītum |

請注意不是所有動詞的完成時詞幹和過去分詞詞幹都可以直接從現在詞幹（字典的第二條目）推出，雖然說「大多數」第一、第二和第四變位法的動詞都可以這麼推。

變位法對於以前兩個詞幹構成的詞形影響比較大，後面的兩個詞幹以及與之相關的詞形可以不管變位法。

## 鼻音中綴現在時
這類動詞的現在詞幹有一個鼻音中綴（一般拼成 n，在 b 或 p 前拼成 m），而完成詞幹則沒有這個鼻音中綴，並且詞根元音通常會變成長元音。

| 假想詞根 | 現在時 | 完成時 | 過去分詞 |
| -- | -- | -- | -- |
| √liqu- | linquō | līquī | lictum |
| √vic- | vincō | vīcī | victum |
| √rup- | rumpō | rūpī | ruptum |
| √fud- | fundō | fūdī | \*fud-tum &gt; \*fussum &gt; !fūsum |
| √iug- | iungō | \*iūxī &gt; !iūnxī | \*iuctum &gt; !iūnctum |
| √pos- | \*posnō &gt; pōnō | posuī | postum &gt; !positum |
