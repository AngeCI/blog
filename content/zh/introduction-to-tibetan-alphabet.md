# 藏文的音節結構
- 前加字（སྔོན་འཇུག་）：5 個
- 上加字（མགོ་ཅན་）：3 個
- 基字（མིང་གཞི་）：30 個
- 元音標記（དབྱངས་）：4 個
- 下加字（འདོགས་ཅན་）：4 個
- 後加字（རྗེས་འཇུག་）：10 個
- 次後加字（ཡང་འཇུག་）：2 個

## 輔音子母
藏文有 30 個基本輔音字母。

|  | 全清 | 次清 | 全濁 | 次濁 |
| -- | -- | -- | -- | -- |
| 藏文字母 | ཀ | ཁ | ག | ང |
| Wylie 轉寫 | k | kh | g | ng |
| 藏文字母 | ཅ | ཆ | ཇ | ཉ |
| Wylie 轉寫 | c | ch | j | ny |
| 藏文字母 | ཏ | ཐ | ད | ན |
| Wylie 轉寫 | t | th | d | n |
| 藏文字母 | པ | ཕ | བ | མ |
| Wylie 轉寫 | p | ph | b | m |
| 藏文字母 | ཙ | ཚ | ཛ | ཝ |
| Wylie 轉寫 | ts | tsh | dz | w |
| 藏文字母 | ཞ | ཟ | འ | ཡ |
| Wylie 轉寫 | zh | z | ' | y |
| 藏文字母 | ར | ལ | ཤ | ས |
| Wylie 轉寫 | r | l | sh | s |
| 藏文字母 | ཧ | ཨ |  |  |
| Wylie 轉寫 | h | ∅ |  |  |

頭五行字母的（古音）清濁屬性與表頭對應；第六行濁音全是濁音，其中 ཞ་ཟ་འ 是全濁，ཡ 是次濁；第七行 ར་ལ 是次濁、ཤ་ས 是清音；第八行是清音。字母的清濁屬性會影響現代發音的調類分化，學習者必須牢記。

## 元音記號
藏文有 4 個基本的元音記號，另外無元音記號也是一種狀態，合共 5 種狀態。

| 元音記號 | 名稱 | 通常發音 | 前化發音 |
| -- | -- | -- | -- |
| ◌ | N/A | a /a/ | ä /ɛ/ |
| ◌ི | གི་གུ་ kìgu | i /i/ | i /i/ |
| ◌ུ | ཞབས་ཀྱུ་ shàpkyu | u /u/ | ü /y/ |
| ◌ེ | འགྲེང་པོ་ trèngpo | e /e/ ~ /ɛ/ | e /e/ ~ /ɛ/ |
| ◌ོ | ན་རོ་ nàro | o /o/ ~ /ɔ/ | ö /ø/ |

元音的前化發音僅在後加字為 ད་ན་ལ་ས 時使用。

- 外來語的長元音可用 ◌ཱ 標記，與上述元音記號結合得 ◌ཱི ◌ཱུ，但 ◌ེ 和 ◌ོ 本身就是長元音（至少從梵語語法的角度而言），它們的超長元音使用另外的形式 ཻ 和 ཽ。
- 梵語的隨韻 anusvāra 在藏文中寫作 ◌ཾ，拼讀作 རྗེས་སུ་ང་རོ་。
- 梵語的止韻 visarga 在藏文中寫作 ཿ，拼讀作 རནམ་བཅད་。
- 梵語的捲舌元音 ṛ 和 ḷ 在音節開頭時藏文寫作 རྀ 和 ལྀ，在其他輔音後寫作 ◌ྲྀ 和 ◌ླྀ。對應的長元音形式為 རཱྀ ◌ྲཱྀ ལཱྀ ◌ླཱྀ。

## 反體字與併體字
反體字（ལོག་ཡིག་）有 6 個：ཊ་ཋ་ཌ་ཎ་ཥ་ཀྵ。拼讀時讀作 ཏ་ལོག་ཊ་ dálog drá、ཐ་ལོག་ཋ་ tálog trá 之類。ཀྵ 拼讀時讀作 ཀ་ཤ་ལོག་ཀྵ་ gá shálog kyá。

併體字（མཐུག་ཡིག་）有 5 個：གྷ་དྷ་ཌྷ་བྷ་ཛྷ，一般僅用於轉寫梵語（或某些現代印度語言）的濁送氣輔音。拼讀時讀作 ཧ་བཏགས་ hádag。

另外巴爾蒂語有四個特殊的字母：ཫ་ཬ་ཁ༹་ག༹。

## 下加字
下加字有 4 個：ཡ་ར་ལ་ཝ（◌ྱ་◌ྲ་◌ླ་◌ྭ），拼讀時分別讀作 ཡ་བཏགས་ yàdag、ར་བཏགས་ ràdag、ལ་བཏགས་ làdag、ཝ་ཟུར་ wàsur。

下加字通常不影響聲調，它只會影響輔音的讀法。

- 下加字 ཡ 可以加在 ཀ་ཁ་ག་པ་ཕ་བ་མ 7 個字母下面，形成 ཀྱ་ཁྱ་གྱ་པྱ་ཕྱ་བྱ་མྱ。第一行輔音帶 ཡ 下加字時讀作硬腭塞音 gy 與 ky；第四行輔音帶 ཡ 下加字時讀作硬腭塞擦音 j 與 ch。མྱ 的讀音與 ཉ 相同。另外有一個用於轉寫外來語的特殊組合 ཧྱ hyá。
- 下加字 ར 可以加在 ཀ་ཁ་ག་ཏ་ཐ་ད་པ་ཕ་བ་མ་ཤ་ས་ཧ 13 個字母下面，形成 ཀྲ་ཁྲ་གྲ་ཏྲ་ཐྲ་དྲ་པྲ་ཕྲ་བྲ་མྲ་ཤྲ་སྲ་ཧྲ。ཀྲ་ཁྲ་གྲ་ཏྲ་ཐྲ་དྲ་པྲ་ཕྲ་བྲ 九個組合讀作捲舌音 dr 與 tr；མྲ་ཤྲ་སྲ 讀音則通常不變[^1]（同基字讀法）；ཧྲ 讀作捲舌擦音 rh。
- 下加字 ལ 可以加在 ཀ་ག་བ་ཟ་ར་ས 6 個字母下面，形成 ཀླ་གླ་བླ་ཟླ་རླ་སླ。ཟླ 讀作陽調 d；其餘五個組合一律讀作陰調 l。
- 下加字 ཝ 可以加在 ཀ་ཁ་ག་ཅ་ཉ་ཏ་ད་ཙ་ཚ་ཞ་ཟ་ར་ལ་ཤ་ས་ཧ 16 個字母下面，形成 ཀྭ་ཁྭ་གྭ་ཅྭ་ཉྭ་ཏྭ་དྭ་ཙྭ་ཚྭ་ཞྭ་ཟྭ་རྭ་ལྭ་ཤྭ་སྭ་ཧྭ。下加字 ཝ 在固有詞中不影響讀音。另外也有雙重下加字的組合如 གྲྭ trà。

## 後加字
後加字有 10 個：ག་ང་ད་ན་བ་མ་འ་ར་ལ་ས。

- 後加字 འ 在不帶元音記號時不發音；帶元音記號 འི 時使主元音延長且前化；帶其他元音記號時形成雙元音；
- 後加字 ག 介乎於發音與不發音之間，發音時讀作音節末尾的 g /k/ 或喉塞音 /ʔ/，不除阻；不發音時仍影響調類分化；
- 後加字 ང 讀作音節末尾的 ng /ŋ/；
- 後加字 མ 讀作音節末尾的 m /m/；
- 後加字 བ 讀作音節末尾的 b /p/，不除阻；
- 後加字 ར 讀作音節末尾的 r /ɹ/，或使主元音延長而不發音；
- 後加字 ད 和 ས 本身不發音，但會使主元音前化；
- 後加字 ལ 介乎於發音與不發音之間，主要是使主元音延長且前化；
- 後加字 ན 會令主元音前化且鼻化。

## 次後加字
次後加字只有兩個：ས 和 ད。次後加字對現代藏語發音影響甚微，但仍會對調類分化產生影響，詳見下文[音節長短的判斷](#音節長短的判斷)。

## 前加字、上加字
前加字有 5 個：ག་ད་བ་མ་འ。上加字有 3 個：ར་ལ་ས。前加字和上加字在古藏語音位上沒有什麼區別，只有書寫位置的差異。前加字和上加字對現代藏語的發音影響主要體現在聲調上，詳見下文[聲母與陰陽調的判斷](#聲母與陰陽調的判斷)。不過當前／上加字出現在雙音節詞的第二個音節，且前面的音節是開音節的話，則這個前／上加字有可能作為單獨的輔音發音。

- 上加字 ར 可以加在 ཀ་ག་ང་ཇ་ཉ་ཏ་ད་ན་བ་མ་ཙ་ཛ 12 個字母上面，形成 རྐ་རྒ་རྔ་རྗ་རྙ་རྟ་རྡ་རྣ་རྦ་རྨ་རྩ་རྫ；
- 上加字 ལ 可以加在 ཀ་ག་ང་ཅ་ཇ་ཏ་ད་པ་བ་ཧ 10 個字母上面，形成 ལྐ་ལྒ་ལྔ་ལྕ་ལྗ་ལྟ་ལྡ་ལྤ་ལྦ་ལྷ；
- 上加字 ས 可以加在 ཀ་ག་ང་ཉ་ཏ་ད་ན་པ་བ་མ་ཙ 11 個字母上面，形成 སྐ་སྒ་སྔ་སྙ་སྟ་སྡ་སྣ་སྤ་སྦ་སྨ་སྩ；
- 基字 ང 和 ད 均可以配上述三個上加字，字形近似須注意分辨；
- 前加字 ག 可以加在 ཅ་ཉ་ཏ་ད་ན་ཙ་ཞ་ཟ་ཡ་ཤ་ས 11 個字母前面；
- 前加字 ད 可以加在 ཀ་ག་ང་པ་བ་མ 6 個字母前面；
- 前加字 བ 可以加在 ཀ་ག་ང་ཅ་ཇ་ཉ་ཏ་ད་ན་ཙ་ཛ་ཞ་ཟ་ཤ་ས 15 個字母前面；
- 前加字 མ 可以加在 ཁ་ག་ང་ཆ་ཇ་ཉ་ཐ་ད་ན་ཚ་ཛ 11 個字母前面；
- 前加字 འ 可以加在 ཁ་ག་ཆ་ཇ་ཐ་ད་ཕ་བ་ཚ་ཛ 10 個字母前面；
- 僅當前加字為 བ 時，前加字和上加字可以同時出現。

## 同時帶上下加字的音節
同時帶上下加字的音節組合非常有限。大致有下列這些：རྐྱ་རྒྱ་རྨྱ་སྐྱ་སྒྱ་སྤྱ་སྦྱ་སྨྱ་སྐྲ་སྒྲ་སྤྲ་སྦྲ་སྨྲ

## 基字的判斷
- 除了韻尾 འི་འུ 以外，帶元音記號的字母為基字；帶上下加字的位置為基字；
- 若無元音記號、上下加字的，則要看音節結構：
    - 兩個字母的讀作 CaC；
    - 四個字母的讀作 CCaCC；
    - 以字母 འ 結尾的，基字是 འ 前面的那個字母；
    - 其餘三字母的組合，有可能為 CaCC 或 CCaC，視乎各種古藏語複輔音的音位配列限制。也有可能兩種讀法都符合音位配列規則，需要強記。

# 現代拉薩藏語語音
以下講述一套[丁香項目](/blog/zh/categories/project-lilac-%E4%B8%81%E9%A6%99%E9%A0%85%E7%9B%AE/)自行制定的現代拉薩藏語拼音系統。這套拼音系統主要參考自 Nicolas Tournadre 與 Sangda Dorje 的《Manual of Standard Tibetan བོད་ཀྱི་སྤྱི་སྐད་སློབ་དེབ།》一書，並補充一些新觀點而成。

## 元音

## 聲母與陰陽調的判斷
- 基字為古清音，一律讀陰調；前／上加字一律不影響發音；
- 基字為古全濁音，一律讀陽調；前／上加字僅影響詞首音節是否送氣；
    - 擦音 ཞ་ཟ 無送氣與不送氣之分，前／上加字不影響發音。
- 基字為古次濁音，無前／上加字的為陽調，有前／上加字的為陰調。
- 下加字 ལ 視作帶上加字的基字 ལ，讀作陰調 l，但 ཟླ 讀作陽調的 d。
    - 同時有 ལ 下加字及前加字時，前加字一律不影響發音，讀作陰調 l。
- དབ དབྱ དབྲ 讀作陰調 w y r，但是無下加字的 དབ 有許多例外讀法。
- 下加字 ཝ 一律不發音。
- 對於雙音節詞第二音節的聲母，送氣的聲母變為不送氣。ལ 讀作 l；ཧྲ 讀作 r。

## 音節長短的判斷
- 沒有韻尾、或後加字為 འ 的屬短音節；
- 後加字為鼻音 མ་ན་ང、流音 ལ་ར 或半元音 འི་འུ 的屬長音節；
- 後加字為塞音 བ་ད་ག 或 ས 的屬入聲音節；帶次後加字的一律也算作入聲音節。
    - ལད རད ནད 的次後加字以及部份 ས 次後加字現代已不再寫出，但仍對現代拉薩藏語的調類分化有影響。

## 現代拉薩藏語的單字調
|  | 短音節 | 長音節 | 入聲音節 |
| -- | -- | -- | -- |
| 陰調 | 54 ˥˦ | 55 ˥˥ | 53 ˥˧ |
| 陽調 | 13 ˩˧ | 114 ˩˩˦ | 231 ˨˧˩ |

## 現代拉薩藏語的雙字調
| 前字陰陽＼後字長短 | 短音節 | 長音節 | 入聲音節 |
| -- | -- | -- | -- |
| 陰調 | 55-54 ˥˥-˥˦ | 55-55 ˥˥-˥˥ | 55-53 ˥˥-˥˧ |
| 陽調 | 21-54 ˨˩-˥˦ | 21-14 ˨˩-˩˦ | 21-53 ˨˩-˥˧ |

藏語的雙字詞有三種情況：一個雙字詞、兩個單字詞、一個單字詞加一個輕聲後綴。

## 輕聲
輕聲音節本身讀作 22 ˨˨，不影響前字調值，且聲母不發生弱化。

## 音節重組
- 若第一音節無後加字或後加字為 འ，第二音節的前加字 ག་བ 可以當作第一音節的 coda 發音；第二音節的前加字 འ་ལ་མ 可以讀作第一音節鼻音韻尾。
