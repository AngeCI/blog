# 我嘅答案
## 你當初點解開始寫部落格？
主要係整嚟擠[筆記](/blog/yue/categories/notes-筆記/)順便嚟黐下 [BlogBlog 同樂會](/blog/yue/categories/blogblog-同樂會/)？我目前仲未將我所有嘅筆記都整理好。

## 你用咩平台去管理你嘅部落格？點解揀佢？
目前唯一用緊嘅「平台」係 GitHub Pages，網站界面本身用 Hugo 生成。或者唔知幾時諗住起留言板嗰陣要考慮租個 VPS。或者唔知幾時諗住將成個網站搬去第個平台度 host。

## 你之前有冇喺其他平台度寫過部落格文章？
好耐之前有稍微掂過下 Blogger，但當時唔似得而家咁有咁多閒情寫 blog，好快就荒廢咗。

## 你點樣寫文？
都係用本地文字編輯器直接改 markdown 檔案喔。

呢個部落格網站有英語同粵語版本，但由於我目前極少喺不諳漢語嘅圈子宣傳呢個網站，所以本站嘅英語內容大部份都是用住機器翻譯工具粗翻一次先，以後有時間先再嚟慢慢校對喇。

## 你咩時候最有寫作靈感？
好難講，唔存在固定時間。

## 你會喺寫完後即刻發佈，定係會存成草稿醞釀下先？
兩樣都有。有時候諗到靈感之後就即刻成篇寫好嘅就會即刻 po 出嚟。有時候淨係諗到一小部份嘅話或者就會存成草稿，亦都有可能會 po 出嚟先遲啲再慢慢執。[BlogBlog 同樂會](/blog/yue/categories/blogblog-同樂會/)之類比較需要灌注心力嘅文章都係分段完成嘅。我覺得短期內我應都唔會有維持到日更嘅毅力，所以亦都無謂囤稿喇。

## 你部落格上最鍾意嘅文章係邊一篇？
本站文章數量暫時唔係好多，好難講。

## 你對部落格有乜嘢未來計劃？
- [ ] 等到網站人流夠多嗰陣，或者會考慮起個留言板？
- [ ] 或者會考慮將成個網站搬去自有網域？
