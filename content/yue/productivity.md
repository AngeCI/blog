# 非完全信息博弈：囚徒困境同納什均衡
這個世界上很多的博弈都是非完全信息的，即參與博弈的各方有着不為其他參與方所知的隱藏資訊。

可以說很多非完全信息博弈所導致的後果，實際上是降低了全世界的整體生產力的。

# 用愛發電
能夠單靠參與自由軟件專案嚟維持生活當然係好[理想](/blog/zh/perfect-days/)，但現實係能夠單單靠開發自由軟件嚟維持生計的人並唔係太多。

現實當中 FOSS 往往靠以下方式來維生：
- 售賣對應的周邊服務（例如 Caddy、cURL、SQLite3 售賣技術支援、以及某吃相糟糕的[打譜軟件](https://wiwi.blog/blog/musescore-com-scam/)）
- 將軟件雙授權，開源軟件可以以開放原始碼協定免費使用依賴，閉源軟件必須購買付費授權（如 Qt、JUCE）
- 獲取專項撥款（如從 NLnet、FOSS.United 等獲取撥款，例如 Rethink）
- 售賣預構建二進位檔案（如 Ardour）
- 獲取政府合同（Tuwunnel 從瑞士政府獲取資助合同）或公司合同（Valve 以公司合同資助一啲 KDE 開發者）
- 收課金（就是純粹的用愛發電，需要足夠有人氣）
- 捐授權協定罅，直接售賣授權（RHEL）

結果就是自由軟件往往淪為唔會被投放充足勞動力的**副業**，造成現在自由軟件市場**質素參差、良莠不齊**。

# 諸神黃昏嘅雙輸局面
> 「自由軟件連嘢都做唔到，咁愛佢把鬼吖？」——佚名

博弈的後果是，很多必要軟件和服務，往往都達不到（所有條件皆）理想的狀況，哪怕現成的選擇其實不少。

Wiwi 就曾經有列出過一個[真·宅男指南](https://wiwi.blog/blog/fake-vs-real-tech-nerd/)。我覺得佢裏面嘅唔少看法（至少在 2026 年當下）實在係有啲太過激進，一些項目實際上並唔太現實。預算不足嘅情況下甚至會構成對生產力嘅拖累。

- 你以為全世界所有人都能力自架離線 AI？我嘅話樽頸唔喺技術力，而係喺某啲天龍人意想不到的嘅方面，請見[下文](#點樣運用人工智能提升生產力？)。
- 「對廣告嘅態度」喺個兩難，上面已經講咗喇。
- 避免訂閱服務（或曰「租用」）聽落好理想好崇高咁，但喺當今呢個諸神黃昏嘅時代，用得嘅買斷制軟件又有幾多？
- 個人使用當然可以避免專有格式，但當你為咗維持生計而不得不出嚟做嘢嘅時候，呢啲專有格式，你以為你完全避到？
- 當自由軟件市場仲係一潭死水嘅狀況下，市場需求自然會更加傾向 Windows 同 macOS 呢啲主流作業系統，開發 Linux 軟件喺商業角度上並不討好。Wine 唔係萬能㗎。
- 自架郵件伺服器你估咁易？實際上喺很多年前就已經被大量嘅 spam mail 玩成咗信任死鎖，自架郵件服務好難出信㗎。
- 即時通訊軟件是諸神黃昏，上面講咗。
