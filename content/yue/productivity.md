# 非完全信息博弈：囚徒困境同納什均衡
呢個世界上好多嘅博弈都係非完全信息嘅，即係參與博弈嘅各方，有住啲其他參與方唔知嘅隱藏資訊。

舉個例子，警局同兩名疑犯做認罪協商，如果兩名疑犯都唔認罪（共同合作），則二人同樣判監半年；如果其中一名疑犯認罪（背叛）而另一名疑犯保持沉默（合作）嘅話，認罪嗰個將即時獲釋，沉默嗰個將判監十年；如果兩名疑犯一齊認罪（互相背叛），咁兩個人就同樣判監五年。而兩名疑犯之間並唔可以互相交流。

|  | 乙合作 | 乙背叛 |
| -- | -- | -- |
| 甲合作 | -0.5, -0.5 | -10, 0 |
| 甲背叛 | 0, -10 | -5, -5 |

呢個就叫做[**囚徒困境**](https://zh-yue.wikipedia.org/wiki/%E7%9B%A3%E7%8A%AF%E5%9B%B0%E5%A2%83)（Prisoner’s dilemma）。你會發現，喺雙方都互相信唔到對方嘅情形下，雙方喺只考慮自身利益時嘅最優策略，居然都係揀背叛！而相互背叛又唔會為雙方帶嚟更好嘅整體利益（只會將單獨考慮每名疑犯自身嘅利益最大化），形成「寧為玉碎，不作瓦全」嘅雙輸局面。當任何一方都冇誘因去單方面改變佢嘅選擇時，**納什均衡**（Nash equilibrium）就形成咗。

可以話好多非完全信息博弈所導致嘅後果，實際上係降低緊全世界嘅整體生產力㗎。[^1]

（如果雙方共同合作嘅收益大過互相背叛嘅虧損，咁就唔叫囚徒困境而係叫[獵鹿博弈](https://zh.wikipedia.org/wiki/%E7%8D%B5%E9%B9%BF%E8%B3%BD%E5%B1%80)。喺獵鹿博弈入面，「共同合作」同「互相背叛」都係納什均衡。）

# 諸神黃昏嘅雙輸局面
面對[百年未有之大便局](https://wiwi.blog/blog/notebooklm-enshittification/)，冇一樣現成產品喺各方面都係完美嘅，你只可以喺各種唔同嘅大便入面揀個最冇咁難聞嘅，然後試下將佢整做你接受到嘅樣。

## 廣告兩難
將囚徒困境套用喺商業層面，就可以解釋成：每間公司都有兩個選擇，一係將更多嘅資源投放落廣告度以求削弱或者打倒競爭對手（互相背叛）；二係同競爭對手互相達成協議，減少浪費喺廣告嘅資源（共同合作）。喺現實嘅商業環境入面，互相背叛極其常見，結果大量嘅資源同網絡流量就被白白浪費咗喺廣告度，而絕大多數嘅消費者其實根本眼尾都唔會睄下。

喺呢場博弈之中，最終受害嘅，竟然係終端用戶。各種過於猖狂嘅廣告迫使終端用戶紛紛開起咗廣告攔截器。隨着 Google 對廣告攔截器嘅宣戰，一場新嘅兩難博弈正悄然打響。某啲（可能有佢存在價值嘅）網站同服務不得不依賴廣告維生如果唔係會餓死，但廣告服務又依賴各種侵犯用戶私隱嘅追蹤器，將注重私隱嘅用戶羣嚇走，但用戶嘅流失又變相威脅到平台嘅財政，形成兩難局面。

## 瀏覽器之戰
先嚟睇睇各位用緊嘅瀏覽器啦。常見嘅瀏覽器有乜優缺點？

- Google Chrome 被人話係間諜軟件同廣告軟件唔係第一天喇。
- Microsoft Edge 界面相對較為煩人，而且亦都被人話係間諜軟件同廣告軟件。
- Firefox 嘅背景望落自由啲，界面比較乾淨，但因為市佔率因素導致某啲網頁可能會對 Firefox 唔係咁友善，而且 [Pront](https://prontlin.com/posts/leave-chrome/#%E7%82%BA%E4%BB%80%E9%BA%BC%E4%B8%8D%E9%81%B8-firefox) 同埋（曾經嘅[^2]）[Wiwi](https://wiwi.blog/use#-%E7%80%8F%E8%A6%BD%E5%99%A8) 都指責佢話係間諜軟件，而且聽講 Firefox Android 版唔係咁好用。
- Brave 被[光鶯社羣](https://ltgc.cc)共同創辦人之一嘅 Lumière Élevé 認為佢應該得到同「威脅用戶安全」嘅瀏覽器同樣嘅待遇（喺光鶯社羣嘅服務之中屏蔽），並稱 Brave「冇人會對呢種畀錢加密貨幣圈嘅嘢落淚，更何況仲係用緊 Google 控制嘅 Chromium 內核[^5]」、「槍斃咗唔心疼[^6]」。
- Safari 係蘋果平台專屬，用咗啲{{< ruby 藞苴 "laa5 zaa2" >}}招去強行保住佢嘅市佔率。
- LibreWolf 比較適合私隱愛好者，但係要加載需要硬體加速嘅頁面嘅話就咪使旨意喇。
- Cromite 應該係喺 Chromium 系瀏覽器入面最注重私隱㗎喇，亦都冇來自加密貨幣圈嘅大便，但它都仲係有一啲來自 Chromium 嘅原罪[^3]。

由上所見，冇一樣現成產品喺各方面都係完美嘅，你只可以喺各種唔同嘅大便入面揀個最冇咁難聞嘅，然後試下將佢整做你接受到嘅樣。

## 即時通訊軟件嘅諸神黃昏
即時通訊軟件都係一團大便，你只能喺各種不同嘅大便入面取捨。

- Discord 商業味太濃，而且仲喺度為年齡驗證單嘢炎上緊噃。
- Telegram 家陣收費功能越搞越多喇，「永遠免費」已成絕響。而且 Telegram 嘅聲音傳輸質量渣過 Discord。
- Matrix 嘅穩定性（特別係基於 Synapse 嘅 homeserver）似乎仲未夠好。
- Stoat 目標係替代 Discord ，雖然打住「反對歧視」嘅標語，但似乎對來自一啲國家嘅人有[地域歧視](https://github.com/stoatchat/for-android/issues/58)，一竹篙打一船人。
- Fluxer 都係 Discord 嘅一個替代品，但佢將 Discord 嘅課金手段都學得別無二致，甚至有過之而無不及。
- SimpleX 用到而且保密性仲係頂尖㗎，但跨裝置登錄就唔使諗喇。
- Signal 雖然加密本身冇乜挑剔，但除咗加密之外嘅地方問題就多喇，除咗私密訊息嘅通知推送包含消息明文之外，背後嘅團隊亦對反審查毫無概念，至今仲喺度向受審查地區嘅用戶推薦佢哋有嚴重問題嘅 TLS 代理，將用戶置身喺危險之中。
- Whatsapp 會將你嘅資料源源不斷咁餵畀 Meta，商業味太濃。

# 用愛發電
能夠單靠參與自由軟件專案嚟維持生活當然係好[理想](/blog/zh/perfect-days/)，但現實係能夠單單靠開發自由軟件嚟維持生計的人並唔係咁多。

現實當中 FOSS 往往靠以下方式嚟維生：
- 售賣對應嘅周邊服務（例如 Caddy、cURL、SQLite3 賣技術支援、以及某個吃相糟糕嘅[打譜軟件](https://wiwi.blog/blog/musescore-com-scam/)）
- 將軟件雙授權，開源軟件可以以開放原始碼協定免費使用依賴，閉源軟件必須購買付費授權（如 Qt、JUCE）
- 獲取專項撥款（如從 NLnet、FOSS.United 等獲取撥款，例如 Rethink）
- 售賣預構建二進位檔案（如 Ardour）
- 獲取政府合同（Tuwunnel 從瑞士政府獲取資助合同）或公司合同（Valve 以公司合同資助一啲 KDE 開發者）
- 收課金（就係純粹嘅用愛發電，需要足夠有人氣）
- 捐授權協定罅，直接賣授權（RHEL）

結果就係自由軟件往往淪為唔會被投放充足勞動力嘅**副業**，造成家陣自由軟件市場**質素參差、良莠不齊**。

# 一潭死水嘅自由軟件市場
> 「自由軟件連嘢都做唔到，咁愛佢把鬼吖？」——佚名

博弈嘅後果係，好多必要嘅軟件同服務，往往都達唔到（所有條件都）理想嘅狀況，哪怕現成嘅選擇其實唔少。

Wiwi 就曾經有列出過一個[真·宅男指南](https://wiwi.blog/blog/fake-vs-real-tech-nerd/)。我覺得佢裏面嘅唔少睇法（至少喺 2026 年當下）實在係有啲太過激進，一啲項目實際上並唔唔係好現實，同燒錢冇乜分別。預算不足嘅情況下甚至只會構成對生產力嘅拖累。

- 你以為全世界所有人都能力自架離線 AI？我嘅話樽頸唔喺技術力，而係喺某啲天龍人意想不到的嘅方面，請見[下文](#點樣運用人工智能提升生產力？)。
- 「對廣告嘅態度」係個兩難，[上面](#廣告兩難)已經講咗喇。
- 避免訂閱服務（或曰「租用」）聽落好理想好崇高咁，但喺當今呢個諸神黃昏嘅時代，用得嘅買斷制軟件又有幾多？
- 個人使用當然可以避免專有格式，但當你為咗維持生計而不得不出嚟做嘢嘅時候，呢啲專有格式，你以為你完全避到？
- 當自由軟件市場仲係一潭死水嘅狀況下，市場需求自然會更加傾向 Windows 同 macOS 呢啲主流作業系統，開發 Linux 軟件喺商業角度上並不討好。Wine 唔係萬能㗎。
- 自架郵件伺服器你估咁易？實際上喺很多年前就已經被大量嘅 spam mail 玩成咗信任死鎖，自架郵件服務好難出信㗎。
- 即時通訊軟件是諸神黃昏，[上面](#即時通訊軟件的諸神黃昏)講咗。

不過我而家仲係經濟拮据。你而家睇到嘅呢個部落格，就連自有網域都仲未有[^4]，更何談各種極其燒錢的自架服務了。

# 人工智能對生產力嘅影響
喺人工智能可以快速搞掂人類以往需要花更多時間同心力先搞得掂嘅嘢嘅背景下，可以話人工智能（喺某些領域嘅）生產力已經超越咗人類。喺呢啲被 AI 主導嘅領域當中，只有最頂尖嘅人類先存活到，生產力追唔上 AI 的人就會被社會淘汰。

- 細個嗰陣有啲憧憬做軟件工程師，但係喺而家 vibe coding 大行其道嘅時代下，單純做個軟件工程師喺商業角度上已經唔係咁討好喇。
- 細個嗰陣有啲憧憬做同人繪師，結果 AI 而家都畫得快過人手兼且品質唔錯喇。
- 靜態嘅翻譯行為，就算冇咁準確都被「夠用就得」踢咗出嚟，只剩低更傷腦筋嘅即時傳譯仲有需求，或者可以考慮轉行做「低資源語言」（如各種漢語「方言」）嘅翻譯。

不過行人工智能好食電，喺當今全球能源危機嘅形勢下，人工智能嘅發展趨勢會唔會被迫放緩？

# 點樣運用人工智能提升生產力？
