My blog currently has three languages: written Chinese, Cantonese, and English. The different language versions are currently distinguished by different paths.

Since I rarely promote this website in circles where people don’t understand Chinese, most of the English content on this site has been roughly translated using machine translation tools, and I’ll proofread it more carefully later when I have time.

[JN](https://blog.giveanornot.com) recently created a tool called [IndiePing](https://indieping.giveanornot.com), which can be used to search for posts in the “[BlogBlog Club](https://blogblog.club/party) Universe” that link to your blog. The tool has a minor bug: if your blog is not under the root directory of a subdomain, IndiePing might retrieve the wrong blog name. JN replied that this bug needs to be manually fixed case by case. Currently, this blog doesn’t have [its own domain](/blog/personal-brand-domain/), but perhaps one day I’ll move the entire blog to my own domain. I wonder if, when moving the domain in the future, the three different language versions should maintain directory distinctions, or if, for compatibility reasons with some blog linking tools, I’ll have to assign different hostnames to each language version.

Additionally, [noeFly](https://need.noefly.cc) is also developing a [blog search engine](https://search.noefly.cc), but it’s unclear how well it supports non-root directory + multilingual blogs like mine.

Eddie Lv somehow decided to include a link to my English website for some reason on his “[Mentions & Discussion](https://eddielv.com/discuss/)” page, even though Eddie’s website is written in Chinese. Perhaps he doesn’t notice that my website actually has a Chinese version.
