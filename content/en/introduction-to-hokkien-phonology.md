# 聲母
閩南語有 14 - 15 個聲母音位，其中濁塞音和鼻音聲母呈互補分佈，並不視作不同的音位（但大多數拼音系統會區分）。半元音 /w/ 和 /j/ 一般會被視作韻母的一部份。

|  | 唇音 | 齦音 | 軟腭音 | 聲門音 |
| -- | -- | -- | -- | -- |
| 不送氣清塞音 | p /p/ | t /t/ | k /k/ | ∅ /ʔ/ ~ ∅ |
| 送氣清塞音 | ph /pʰ/ | th /tʰ/ | kh /kʰ/ |  |
| 濁塞音 | b /b/ | l /l/ ~ /d/ ~ /ɾ/ | g /g/ |  |
| 鼻音 | m /m/ | n /n/ | ng /ŋ/ |  |
| 不送氣清塞擦音 |  | ch, ts /ts/ |  |  |
| 送氣清塞擦音 |  | chh, tsh /tsʰ/ |  |  |
| 濁塞擦音 |  | j /dz/ ~ /z/ |  |  |
| 清擦音 |  | s /s/ |  | h /h/ |

在 i 前面（不管是介音還是主元音），/ts/, /tsʰ/, /dz/ ~ /z/, /s/ 會腭化成 /tɕ/, /tɕʰ/, /dʑ/ ~ /ʑ/, /ɕ/，但因為不構成音位對立，大多數拼音系統不作區分。

有些口音沒有 /dz/ 聲母，併入 /l/ 或者 /g/。

# 韻母
閩南語的韻母體系龐大且複雜，排成表格的話欄目眾多，且空格也有點多，不太整齊。我能找到的大部份閩南語教材，韻母表大多是一維排列的，很少有將之整理之二維表格形式的。

以下描述的系統一套常見於臺灣教材的「最大公約數音系」。有些閩南語方言可能具備位於這套「最大公約數系統」以外的韻母甚至元音音位，但絕大多數閩南語都具備在「最大公約數音系」中的元音音位。

閩南語的「最大公約數音系」一般有六個基本元音，但有少數人的腔調無法區分 o /o/ ~ /ə/ 和 o͘, oo /ɔ/。

其中 /iŋ/ 的實際（正統）發音其實更像 [i̯əŋ]，跟 /in/ 有很大差別。臺灣華語 /iŋ/ 混入 /in/ 的趨勢其實看着有點奇怪。

大部份的陰聲韻都有對應的鼻化韻及喉塞韻尾，但也有例外的不成配對的陰聲韻。鼻化韻以 -ⁿ, -nn 表示，喉塞韻尾以 -h 表示。有些口音的喉塞韻尾不是很明顯（甚至受普通話影響[傳染到其他入聲韻](/blog/zh/chinese-dialectal-phenomena/#閩南語真的是保留入聲的語言嗎)），可能要查字典確認。

另外還有幾個孤零零難以歸類的 oe, ue /ue/ 和 iong /ioŋ/。閩南語「最大公約數音系」裏面沒有 /uam/ 跟 /uaŋ/（分別併入 /uan/ 和 /oŋ/），但一些方言裏確實有這樣的發音。

文讀系統中較少出現鼻化韻，但一些字即使在文讀音裏，也會受到鼻音聲母的影響而發生鼻化。也有小部份隨機發生鼻化的文讀音。當鼻化發生時，/ɔ/ 和 /o/ ~ /ə/ 會合併成 /ɔ̃/。

# 聲調
文白讀系統之間的聲調差異並不多。大多數差異在於古次濁聲母上聲的歸併（文讀併入陰上、白讀大多數腔調併入陽去），以及陰陽入的交替。

閩南語有着複雜的變調系統，每一個聲調都有本調和變調兩套調值。至於一個音節什麼時候該唸本調，什麼時候該唸變調，Yoxem 有做過一個[非常詳細的論述](https://blog.kianting.info/2020/04/20/ho-lo-ue-e-ku-tiong-lian-siok-pian-tiau/)。

| 調號 | 傳統名稱 | 羅馬字 | 本調調值 | 變調調值 |
| -- | -- | -- | -- | -- |
| 1 | 陰平 | ◌, a | 44 | 22 |
| 2 | 陰上 | ◌́, á | 53 | 44 |
| 3 | 陰去 | ◌̀, à | 21 | 53 |
| 4 | 陰入 | ◌H, ah | 32 | 54 |
| 5 | 陽平 | ◌̂, â | 214 | 21/22 |
| 6 | （陽上） | (◌̌, ǎ) | 22 | 21 |
| 7 | 陽去 | ◌̄, ā | 22 | 21 |
| 8 | 陽入 | ◌̍H, a̍h | 4 | 32 |
| 9 | N/A | ◌̋, a̋ | N/A | 35 |

第九聲 a̋ 僅用於三疊詞和外來語，沒有本調。許多教學也根本不列出這個第九聲。

每個變調調值剛好可以對應到一個本調調值，因此也有了像 573217 或 532173、4 變 2、8 變 3 之類的記憶口訣。
